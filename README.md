# LP Solver · 二元线性规划可视化求解器

在线访问：<https://sinxcosx.cn>

一个运行在浏览器里的二元线性规划可视化工具：输入约束与目标函数后，实时绘制每条约束对应的可行半平面、求交得到可行域，并用可拖动的目标等值线演示从起点扫到最优点的求解过程。

纯 HTML / CSS / JavaScript + Canvas 实现，无后端依赖。可直接打开运行，也可部署到任意静态托管平台（项目使用 EdgeOne Pages）。

## 功能特性

- **多色半平面着色**：每条约束使用不同颜色渲染其可行侧，重叠交集即为最终可行域，并单独高亮。
- **仅显示可行域**：可切换隐藏各约束半平面，只保留最终可行域，更聚焦于解空间。
- **目标函数与等值线**：输入如 `4x1 + 3x2` 的目标函数，支持最大化 / 最小化；等值线显示真实的 `Z = …` 数值，可自由拖动。
- **顶点吸附**：拖动等值线时可自动吸附到可行域顶点，方便对齐候选最优解。
- **求解动画**：等值线从可行顶点的起始端（最大化从最小 Z 起，最小化反之）平滑扫到最优点；到达最优值时等值线变黄并播放强调动效。没有可用顶点时从原点 `(0,0)` 起步。
- **手动求解**：即使关闭“自动求解与等值线动画”，点击“求解”也会从当前等值线位置播放一次到最优的动画。
- **约束管理**：添加后可随时编辑或删除约束，颜色与顺序保持不变。
- **顶点列表**：求解后列出可行域全部顶点及其目标值，最优顶点高亮。
- **状态面板**：求解过程中实时显示当前 `Z` 与对应位置；到达最优后显示最终 `Zmax / Zmin` 和最优坐标。
- **交互视图**：支持平移拖拽、滚轮 / 按钮 / 滑条缩放、手机双指缩放；坐标轴使用 1/2/5 刻度，避免放大时挤满小数。
- **响应式与动画**：桌面端为左侧面板，手机竖屏自动变为底部菜单；顶栏、结果卡片与菜单均使用圆角卡片风格，并包含 GSAP 动画（无网络时自动回退到原生动画）。
- **主题与导出**：支持亮 / 暗主题切换，可将当前画布导出为 PNG。

## 使用说明

### 输入语法

- 变量名使用 `x1`、`x2`，系数可省略（如 `x1` 等价于 `1x1`）。
- 支持负号 `-`，也兼容全角减号。
- 约束支持三种关系：`<=`、`>=`、`=`，常数可以写在不等式两边。
- 目标函数直接输入线性表达式即可，如 `4x1 + 3x2`。

示例：

```text
2x1 + 3x2 <= 15
x1 + x2 <= 7
x1 <= 5
x2 <= 4
x1 >= 0
x2 >= 0
```

目标函数示例：`4x1 + 3x2`，优化方向选择“最大化”或“最小化”。

### 基本操作

- 在“约束条件”输入框输入约束并回车或点击“添加约束”。
- 在“目标函数”输入框输入目标函数，选择优化方向后点击“求解”。
- 鼠标拖动画布可平移视角；滚轮、顶部缩放按钮或缩放滑条可改变缩放。
- 鼠标靠近目标等值线时出现竖直拖拽光标，拖动即可改变 Z 值（开启“等值线自动吸附顶点”时会吸附到顶点）。
- “自动求解与等值线动画”开启后，约束或目标函数变化会自动播放求解动画。
- 约束列表中的 ✎ 可回填编辑，× 可删除；“清空”可移除全部约束。

## 运行与部署

### 本地运行

无需构建，直接用浏览器打开 `tools/index.html` 即可。

### EdgeOne Pages 部署

项目根目录已包含 `edgeone.json`，前端输出目录为 `tools`。安装 EdgeOne CLI 后：

```bash
npm install -g edgeone
edgeone login --site <china|global>
edgeone makers deploy -n lp-solver --json
```

也可以在 `tools` 目录使用 `npm run dev` / `npm run deploy`（需要先配置 EdgeOne 登录与 Token）。

## 技术栈

- HTML5 Canvas 绘制坐标轴、半平面、可行域与等值线
- 原生 JavaScript 负责状态与交互（无框架）
- GSAP 3 负责动画时间线；加载失败时自动回退到 `requestAnimationFrame`
- CSS 变量实现亮 / 暗主题与响应式布局
